# Setdue portfolio projects

This repository contains two beginner-to-intermediate portfolio prototypes:

- [Apex Logistics](ApexLogistics/README.md) — local delivery dispatch dashboard.
- [EnterprisePOS](EnterprisePOS/README.md) — local point-of-sale and inventory demo.

Both run in a modern browser without packages or a backend. Their documentation explains setup, scope, limitations, and learning steps. The third portfolio project, LoginShield NG, remains in its existing repository: https://github.com/Setdue/LoginShieldNG.
